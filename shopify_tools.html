STEP 1: Prepare Product CSV

  1. Go to your Shopify Admin page and export the products that you want to sync.

STEP 2: Open the Tool and Import Your CSV

  1. Open this link: Shopify Tools

  2. Click Import CSV and choose the file you exported in Step 1.

    Once the file is imported, the app will show a preview table of your products.

    If you try to import a file that is very large (50 handles or more), the app will warn you that fetching may take a while. This is just a heads-up — you can still continue.

STEP 3: Set Up Configuration

Click the Configuration button to open the settings panel. Everything you set here is saved in your browser, so you only need to set it up once — it will still be there the next time you open the tool.

  1. Store Origin: Enter your Shopify store's web address (for example https://examplestore.myshopify.com). This tells the tool where to fetch the latest product information from.

  2. Visibility

    • Publish products: Turn this on to mark products as published and active after fetching.

    • Inventory Policy Continue: Turn this on to allow customers to keep buying a product even after it is out of stock.

  3. Handle Suffix: If you want to create duplicate products for a special sale or occasion, type a short suffix here (for example sale). It will automatically be added to the end of each product's handle after fetching.

  4. Append Tags: Type one or more tags here, separated by commas (for example preorder, sales). They will automatically be added to every product's tags after fetching — handy if you want the products to show up in a specific collection.

  5. Columns: This is a checklist of every column in your CSV file.

    • Checked means that column will be refreshed with the latest information from your store when you fetch.

    • Unchecked means the tool will leave that column exactly as it is in your imported CSV, even after fetching.

    • A few columns, such as Handle, are shown in bold with a checkbox that cannot be changed. These columns can never be refreshed automatically, because they are used to uniquely identify each product — always keeping your original value avoids accidentally mixing up products.

  6. When you are done, click Save to keep your changes, or Close to discard them and leave everything as it was.

STEP 4: Fetch the Latest Product Data

  1. Click the Fetch button to start pulling the latest product data from your store, using the settings you configured in Step 3.

    A short message will appear letting you know roughly how long the fetch will take. While it is running, the button will show Fetching and the table will keep showing your current data.

  2. Once fetching finishes, the table automatically updates to preview the merged result — combining your original CSV with the fresh data, following the Columns choices you made in Step 3.

  3. If one or more products could not be fetched (for example, if a product no longer exists on your store), a message box will appear listing which ones failed and why. All the other products that were fetched successfully are kept — you just need to click OK to acknowledge the message and continue.

STEP 5: Download the Updated CSV

  1. Click the Download button to save the CSV file shown in the preview table to your computer.

    You do not have to fetch first — this button is available as soon as a CSV is imported, so you can also use it to simply save a copy of your original file.

STEP 6: Rollback and Detach

After fetching, you have two ways to undo what you have done.

  1. Click Rollback.

    This discards the freshly fetched data and brings the table back to showing only your original imported CSV. This button is only available after a successful fetch.

  2. Click Detach.

    This removes the imported file from the app completely and resets everything, so you can import a different CSV file from scratch.

NOTE

To protect your store's pricing and inventory from being overwritten by another source, the following columns are never changed when fetching, are always hidden from the preview table, and cannot be turned on in the Columns checklist:

  1. Variant Inventory Qty
  2. Variant Price
  3. Variant Compare At Price
  4. Unit Price Total Measure
  5. Unit Price Total Measure Unit
  6. Unit Price Base Measure
  7. Unit Price Base Measure Unit
  8. Size Chart (product.metafields.bwp_fields.size_chart)

A small number of other columns, such as Handle, are still shown in the preview table and the Columns checklist, but cannot be refreshed from your store — the tool always keeps your original value for these, since they are used to uniquely identify your products.
